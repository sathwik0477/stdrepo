# Student Portal Web Application

A simple dynamic Java web application for managing student records.

The application is built using Java Servlets, HTML, CSS, and JavaScript and is packaged as a WAR file for deployment on Apache Tomcat 10.

## Features

- Student dashboard
- View registered students
- Add new students
- Dynamic student records
- Form validation using JavaScript
- Responsive user interface
- Java Servlet-based backend
- WAR package deployment
- Compatible with Apache Tomcat 10

## Technologies Used

- Java
- Jakarta Servlet API
- Apache Tomcat 10
- HTML5
- CSS3
- JavaScript
- Maven
- Git & GitHub
